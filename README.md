# ネスペ暗記カード PWA

カード本文を公開サーバへ置かず、暗号化ファイルをiPhoneへ直接取り込んで使う暗記カードアプリです。

## 安全上の境界

- 公開リポジトリへ置くのは、このアプリのソースと `docs/` の静的アプリだけです。
- `cards/*.yaml`、PDF、`.nwdeck`、`.nwbackup`、復号済みJSONは公開しません。
- カード、履歴、設定はAES-256-GCMで暗号化してIndexedDBへ保存します。
- パスフレーズは保存、送信、ログ出力しません。
- 外部API、解析、広告、Cookie、CDN、外部フォントは使用しません。

詳しい脅威境界と停止条件は [SECURITY.md](SECURITY.md) を参照してください。

## ローカル検証

Node.js 22以降を使用します。

```sh
npm ci
npm run verify
```

`verify` は暗号・履歴・件数テスト、型検査、プロダクションビルド、公開物検査、本番依存関係監査を行います。一つでも失敗した場合は公開しません。

## 暗号化デッキを作る

```sh
npm run deck:create
```

対話型ターミナルでパスフレーズを2回入力します。入力文字は画面へ表示されません。生成物は、この公開アプリの外側にある `../private-output/` へ、上書き禁止・所有者だけが読める権限で保存されます。

パスフレーズは12文字以上、または空白区切りの4単語以上にしてください。短いほど推測されやすくなるため、可能なら長くランダムな値を使い、アプリやリポジトリへ保存せず、信頼できるパスワードマネージャへ保存してください。

## iPhoneで使う

1. 公開URLをSafariで開く。
2. 共有メニューから「ホーム画面に追加」し、「Webアプリとして開く」を有効にする。
3. `.nwdeck` をiCloud Driveなどへ移し、アプリの「暗号化デッキを取り込む」から選ぶ。
4. パスフレーズを入力して学習を開始する。
5. 設定から日時付き `.nwbackup` を作り、Mac側とiCloud Drive側に復元確認済みの2世代を保持する。

無操作やバックグラウンド経過による自動ロックは行いません。画面上部の「ロック」を押すか、アプリを終了してください。

## GitHub Pagesへ公開する

公開前にGitHubアカウントのPasskey/2FA、別保管した復旧コードを確認してください。確認できない場合は公開を中止します。

```sh
npm run pages:prepare
```

その後、専用の公開リポジトリ `nw-flashcards` へこのディレクトリだけを登録し、GitHub Pagesの公開元を `main` ブランチの `/docs` に設定します。GitHub Actions、独自ドメイン、有料機能は使用しません。

公開前に `git status` と `git ls-files` を確認し、カード原本、PDF、暗号化デッキ、バックアップが含まれていないことを再確認してください。
